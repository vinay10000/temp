# Real-time ASCII Camera (Matrix Style)

A Next.js (App Router) + Tailwind CSS web app that renders your webcam feed as live ASCII art with a cyberpunk terminal UI.

## Features

- Real-time webcam to ASCII conversion
- Start/stop camera
- Mirror mode toggle
- Resolution slider
- Charset presets (dense, minimal, matrix)
- Multiple color effects (matrix, original, grayscale, amber, inverted)
- Brightness and contrast controls
- Block size (font size) control
- TXT and PNG export
- FPS limiter toggle + FPS indicator
- Fullscreen mode
- Matrix rain background, scanlines, glow, and flicker effects

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```
